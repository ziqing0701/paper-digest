# Paper Digest

顶刊论文精读与科研训练归档站。

## 结构

- `index.html`：归档首页，只展示论文元数据和短摘要，便于搜索与筛选
- `archive.json`：论文元数据、去重记录与周报定位
- `style.css`：统一样式
- `reports/YYYY-Www.html`：每个 ISO 自然周一个完整周报，例如 `reports/2026-W41.html`
- `assets/figures/YYYY-Www/`：在明确许可条件下存放周报中需要展示的关键论文图；`assets/figures/example-evidence.svg` 为模板自制概念示意

## 核心原则：按科学问题与证据链组织全文

`archive.json` 的 `summary` 仅用于首页检索。周报 HTML 保存完整精读，延续原论文的证据推进、关键数值、数学逻辑和科研判断过程。中文精读目标篇幅：常规每篇 1500–2500 字，重大且高度相关论文可扩至 2500–4000 字，以论文特异性内容为准。

**禁止把“图表解读”“公式讲解”“进一步精读公式”设为与论文论证平行的独立大章节。** 图表和公式是对应方法、推导、结果及机制检验的组成部分，必须在被使用时就地解释，并与研究问题、证据强度和下一步研究决策直接关联。避免先单独讲一遍故事、再逐项讲方法结果、最后重新讲一遍故事的重复结构。

## 每篇论文统一结构

论文标题、作者、期刊、年份、DOI/官方链接和“一句话抓核心”放在正文开头作为文献信息区。正文统一设为六个主要章节：

1. **现象、已有认知与真正的科学问题**：讲清观察到的矛盾、先前解释、知识缺口、研究重要性与可检验的问题。
2. **核心假设、理论机制与模型起点**：说明可证伪的假设、关键变量、理论机制及必要公式，直接解释相关量的单位、物理/经济含义和适用条件。
3. **研究设计、证据递进与科学结论闭环**：这是一整个主要章节，内部包含若干自然推进的小节，所有数据、实验、模型、Figure/Table、定量结果与对应公式都在该章节就地讲解。建议小节：**3.1 第一层证据：基础事实与研究设计；3.2 第二层证据：区分竞争机制；3.3 第三层及后续证据：机制检验、稳健性与外推；3.4 科学结论怎样形成闭环**。根据论文实际逻辑灵活调整小节数量与标题，持续回答“上一层为何不够、下一层如何补足、证据支持到哪一步”。
4. **2–4 个关键创新点与高水平发表逻辑**：区分问题、方法、数据、机制与普适性创新，讨论决定性的Figure、核心证据、方法可信度和论文叙事结构。
5. **批判性阅读与可延伸问题**：具体识别局限、数据边界、稳健性风险和审稿人最值得追问的科学问题。
6. **结合用户研究的 1–3 个科研迁移启发与科研判断训练**：明确具体课题、需补充的实验/模型/数据、拟形成的Figure及研究路线。金融论文在此区分学术结论与可迁移投资启示、适用条件和失效边界。

**章节层级要求**：HTML 中六个主要章节采用同级 `<h3>`，第三章下的证据环节采用 `<h4>`，并编号为 3.1、3.2、3.3、3.4 等。图像和公式属于相应证据小节内部，不各自设立独立大章。
**就地解读公式**：引用论文原文式号（如 Eq. (3)），尽量核对原文，使用 MathJax 排版，说明每个变量、单位、物理/经济意义、近似条件，以及它如何指导数据选择、反演、机制检验或模型识别；若为读者辅助推导、机制示意式，应明确标注「概念性示意，非原文公式」。只解释推动论文逻辑的关键公式。

**就地解读图表（图片优先）**：每篇优先挑选 1–3 张最能推进科学论证的关键图，紧邻它支持的假设、方法或证据段落展示。可明确确认该图片具有有效复用许可（如文章 CC BY 且该图未注明第三方权利）时，优先使用出版社可核验的原始图文件，并在权限及工具支持下保存到 `assets/figures/YYYY-Www/<paper-slug>-figN.png`、`.webp` 或 `.svg` 后，通过周报中的相对路径 `../assets/figures/...` 引用。嵌入代码使用 `<figure class="paper-figure"><a href="原图文件链接"><img src="相对路径" alt="精准描述" loading="lazy" decoding="async"></a><figcaption>...</figcaption></figure>`。图片等比缩放、支持手机浏览和点击放大。图注必须标出原文 Fig./Table 编号与 panel、对应 DOI 或官方图表链接、版权归属与具体复用许可，并当场说明轴、颜色/分组、对照、关键数字与误差、图表能支持的推断以及为何转向下一层证据。开放获取、免费阅读本身不足以确认单张图片可转载，务必检查文章许可及图中第三方素材的单独署名。

**受限图像替代**：单张图许可不清楚、无法可靠取得图片、期刊不允许复用、或图像上传工具不可用时，在对应证据段落插入 `<div class="figure-link-only">...` 说明图号、图意、结论及原文 Figure/DOI 链接。对确实需要帮助理解的机制，可使用明确标注“教学概念示意、非论文原图”的原创简化示意图，避免以重绘之名临摹有版权的图或冒充论文原始数据。图表图片需有真实来源，失效链接或图片上传失败时显示图表解读与来源链接，禁止留下破图、空框或未经核验的 Figure 编号。

**每层证据必须回答**：「这一步为什么要做？用了什么方法（及公式）？图表究竟显示什么？能够推断到哪一步？为什么还要继续？」证据链和科研故事线在正文一次性讲清，末尾只对创新与可信度进行高层评价，避免重新复述全文。

## 自动化约定

同一自然周只维护一个 HTML。每次推送后：

1. 读取 `archive.json` 做 DOI / 标题 / 主题去重；
2. 检索并核验 1–2 篇高质量论文；
3. 计算 ISO 周；
4. 创建或追加 `reports/YYYY-Www.html`；
5. 周报正文按上述“完整精读版”标准写入，禁止只写简短 fact table；
   优先在相应证据段落插入经核验、许可允许转载的 1–3 张关键图，图片存入 `assets/figures/` 并以相对路径引用；受限时改用图表讲解框与官方链接；
6. 向 `archive.json` 添加短元数据和周报锚点；
7. `report_url` 指向周报中的对应论文锚点；
8. 首页继续保持简洁，完整内容只放在周报页。

## 叙事强制要求

完整精读必须有“层层引导”，不能只罗列六个栏目。推荐写法：

- 先指出现象或矛盾；
- 解释为什么已有解释仍不够；
- 引出下一组数据、实验或模型；
- 明确这一层结果排除了什么、还留下什么；
- 再进入下一层；
- 最后形成闭环。

每一层尽量回答一句：“为什么这里还不能停，作者为什么必须继续做下一步？”

对历史归档，若聊天中已有完整精读，应优先保留/重构原有论证顺序；以后新推送则直接把聊天精读正文同步到当周 HTML，仅做网页排版，不再重新摘要。


## 篇幅与深度下限

- 常规论文：每篇中文精读目标约 1500–2500 字；
- 特别重要、与用户研究高度相关的论文：可继续扩展到 2500–4000 字；
- 禁止为了凑篇幅加入通用套话，新增内容必须是论文特异性的；
- 关键公式和关键图表在正文相关方法或证据段落就地解释；证据强度分层在逐层论证中完成；审稿视角和下一步研究放在批判性阅读与科研迁移章节；
- 对已有对话中已经做过详细拆解的论文，优先保留原有数字、公式、实验顺序、机制排除过程和推导节奏。
